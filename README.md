# Domain Traffic Inspector

Chromeのサイドパネルで、現在のタブから発生する通信をドメイン別に確認し、通信ルールを管理するManifest V3拡張機能です。計測データとルールは端末内で処理され、開発者のサーバーへ送信されません。

## 主な機能

- ドメイン別のリクエスト数とリソース種別のリアルタイム表示
- 通常モードでの個別ブロック
- 厳格モードでの全ドメイン既定ブロックと許可リスト
- メモ・タグ付きルール管理、検索、一括操作
- ルールのJSONインポート／エクスポート
- ライト／ダークテーマ、キーボードフォーカス、狭いサイドパネルへの対応

> ブロック設定と通信ポリシーは全タブ共通です。拡張機能は開いている全タブの通信先ドメインを端末内でタブ別に集計し、サイドパネルには選択中のタブだけを表示します。

## インストール（開発版）

1. このリポジトリを取得します。
2. Chromeで `chrome://extensions` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」からリポジトリのルートを選びます。
5. ツールバーのアイコンからサイドパネルを開きます。

Chrome 114以降が必要です。

## 権限

- `webRequest` / `<all_urls>`: 全タブの通信先ドメインとリソース種別を端末内でタブ別に集計し、通信ルールを全タブへ適用するため
- `declarativeNetRequest`: ユーザーが指定したドメインをブロックするため
- `storage`: ルール、設定、セッション中のタブ別集計を端末内に保存するため
- `sidePanel`: UIをChromeサイドパネルに表示するため

詳細は[プライバシーポリシー](PRIVACY.md)を参照してください。

## 開発

```sh
npm ci
npm run lint
npm test
npm run test:coverage
```

テストはドメイン判定、Chrome APIをモックしたService Worker、JSDOM上のサイドパネル描画・操作を対象にしています。リリース前には[手動スモークテスト](SMOKE_TEST.md)も実施します。

## リリース

`manifest.json`と`package.json`のバージョンを一致させ、`v1.1.0`のようなタグをpushするとGitHub Release用ZIPが生成されます。タグのバージョンとmanifestが一致しない場合は失敗します。

## 判定について

「広告候補」「CDN候補」「サードパーティ」は補助的な推定です。セキュリティ上の安全性を保証するものではありません。ブロック件数ではなく、観測したリクエスト件数を表示します。
